# Research notes
Raw material from research sessions: paper reads, software evaluations, method comparisons.
Distilled upward into docs/background.md; these files hold the detail that would bloat it.

One file per topic or paper: `<topic>.md` or `<firstauthor_year>.md`. Header:

```markdown
# <title>
date: YYMMDD · type: paper | software | comparison · distilled into background.md: no
citation: Author et al., Year, Journal, doi:…

## Why we read this
## Key findings relevant to us
## Methods or parameters we would reuse
## Caveats
## Implication for our plan
```

PDFs are not committed. Keep them outside the repo and cite by DOI.
